البحث في محتوى المكتبة

افتح وثيقة مفهرسة لمراجعتها، أو أضف نصاً جديداً كمسودة.

تحرير مسودة

لا يظهر النص للقارئ حتى يُراجع ويُعتمد للنشر.

مسودات المراجعة

المسودات غير منشورة ولا تدخل في البحث العام.

وثائق تستدعي المراجعة

مؤشرات الفهرسة لا تعني اعتماد النص قانونياً.

إنشاء حساب دخول

يُنشأ لكل شخص حساب مستقل. تظهر كلمة المرور المؤقتة مرة واحدة، ويُطلب من المستخدم تغييرها عند أول دخول.

الحسابات الحالية

يمكن تعطيل الحساب أو إصدار كلمة مرور مؤقتة جديدة.

الفحص الآلي لأرشيف Drive

آخر حالة يعرضها سجل GitHub Actions؛ افتح سجل التشغيل لمعرفة الملفات الجديدة أو المعدلة.

جارٍ التحقق—فتح سجل الفحص والتشغيل اليدوي

الفحص المجدول يرصد بيانات الملفات فقط؛ لا ينزّل PDF ولا يشغّل OCR تلقائياً.

الاتصال بأرشيف Google Drive

يُجلب الأصل من Drive وقت المعاينة أو التحميل؛ لا تحفظ المكتبة نسخة PDF على خادمها.

جارٍ التحقق

مجلد الأصول: —

أضف محتوى ملف JSON لحساب الخدمة في Render كسر باسم GOOGLE_SERVICE_ACCOUNT_JSON، واحتفظ بمشاركة مجلد الأصول معه بصفة مشاهد. هذا السر ليس مفتاح API ولا يوضع في GitHub أو الواجهة.

فتح أرشيف Drive

محرك OCR

اختر محركاً قبل تشغيل OCR يدوياً من بطاقة ملف Drive. لا يبدأ أي مسح تلقائياً؛ النص الناتج يحفظ كمسودة تحتاج المراجعة والاعتماد.

Gemini لا يعمل إلا بعد اختيار المحرك السحابي ثم الضغط على OCR السحابي وتأكيد الإرسال. قد تُحتسب رسوم بعد الحصة المجانية. OCR المتصفح يعالج PDF في الذاكرة، ويحفظ النص فقط كمسودة. يُحفظ مفتاح Gemini مشفراً ولا يُعرض بعد الحفظ.

الصلاحيات

القارئاطلاع وبحث وقراءة فقط؛ لا إضافة ولا تعديل ولا حذف.
مدير المكتبةإدارة الإعدادات، إعداد المسودات، المراجعة واعتماد النشر.

بيانات الدخول منفصلة عن منصة قلم وتُدار من متغيرات سرية لخدمة المكتبة على Render.

النصوص المنشورة من هذه اللوحة تُحفظ في MongoDB الخاصة بالمكتبة. سجل المصدر والمراجعة يُحفظ مع كل اعتماد.
