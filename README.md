# مكتبة قلم المستقلة

تطبيق المكتبة القانونية المغربية. هذا المستودع للتطبيق فقط، منفصل عن منصة قلم لإدارة المكاتب.

## تشغيل محلي

يتطلب Node.js 24.2 أو أحدث. ضع قاعدة البيانات النصية التي يوفرها مستودع Qalam-Library-data في `data/library.sqlite` ثم شغّل:

```sh
npm start
```

## النشر

ينشر هذا المستودع كخدمة مستقلة على Render. ملفات PDF الأصلية تبقى في Google Drive. لا تُرفع ملفات PDF أو أسرار الاتصال أو نسخ MongoDB إلى GitHub.

## الحالة

المصدر الأولي ما زال قيد النقل من نسخة العمل المحلية. صفحة الدخول متعددة المستخدمين وربط Drive وMongoDB يجب أن يكتمل قبل النشر العام.
